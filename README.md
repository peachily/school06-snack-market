## 활동 목표
현금을 자릿값에 맞게 옮겨 네 자리 수를 만들고, 완성된 수를 읽을 수 있도록 합니다.

## 활동 방법

1. 1·2·3 탭에서 학생을 선택합니다.
2. 지갑의 현금을 같은 자리의 숫자 칸으로 드래그합니다. 현금을 탭한 뒤 숫자 칸을 탭해도 됩니다.
3. 모두 옮기면 숫자가 연결됩니다. 함께 읽은 뒤 과자 옆 삼각형 버튼으로 다음 문제로 넘어갑니다.

키보드는 Tab으로 현금을 찾고 Enter 또는 Space로 선택·이동합니다. 방향키로 숫자 칸을 이동하고 Escape로 선택을 취소할 수 있습니다.

학생마다 과자 30종을 한 번씩 진행합니다. 학생을 바꿔도 진행 상태는 유지됩니다. 상단 다시 시작은 현재 학생만 초기화하고, 브라우저 새로고침은 모두 초기화합니다.

## 학생별 난이도

| 학생 | 출제 범위 | 예시 |
| --- | --- | --- |
| 1 | 천의 자리 1~9, 나머지 0 | 3000, 7000 |
| 2 | 천·백의 자리 각각 1~9, 십·일의 자리 0 | 2400, 6800 |
| 3 | 천의 자리 1~9, 백·십·일의 자리 각각 0~9 | 1020, 5007, 8430 |
