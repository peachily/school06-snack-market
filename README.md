# 얼마일까요?

[활동 바로가기](https://school06-snack-market.pages.dev/)

## 활동 목표
현금을 자릿값에 맞게 옮겨 네 자리 수를 만들고, 완성된 수를 읽을 수 있도록 합니다.

## 활동 1: 얼마일까요?

### 활동 방법

1. 1·2·3·4 탭에서 단계를 선택합니다.
2. 지갑의 현금을 같은 자리의 숫자 칸으로 드래그합니다. 현금을 탭한 뒤 숫자 칸을 탭해도 됩니다.
3. 모두 옮기면 숫자가 연결됩니다. 함께 읽은 뒤 화면 오른쪽 삼각형 버튼으로 다음 문제로 넘어갑니다.

키보드는 Tab으로 현금을 찾고 Enter 또는 Space로 선택·이동합니다.
방향키로 숫자 칸을 이동하고 Escape로 선택을 취소할 수 있습니다.

단계마다 과자 30종을 한 번씩 진행합니다. 단계를 바꿔도 진행 상태는 유지됩니다.
상단 다시 시작은 확인 후 현재 단계만 초기화합니다. 브라우저를 새로고침하면 두 활동 모두 초기화되고, 「얼마일까요?」 1단계가 표시됩니다.

### 단계별 난이도

| 단계 | 출제 범위 | 예시 |
| --- | --- | --- |
| 1 | 천의 자리 1~9, 나머지 0 | 3000, 7000 |
| 2 | 천·백의 자리 각각 1~9, 십·일의 자리 0 | 2400, 6800 |
| 3 | 몇천 몇백 몇십: 천·십의 자리 1~9, 백의 자리 0~9, 일의 자리 0 | 1020, 8430 |
| 4 | 몇천 몇백 몇십 몇: 천·일의 자리 1~9, 백·십의 자리 0~9 | 1007, 5023, 8431 |

각 단계의 첫 3문제는 사용하는 자리에 1~5만 나오며, 단계상 고정된 0은 유지합니다.
4번째부터는 표의 전체 범위에서 출제합니다. 다시 시작하면 첫 3문제의 적응 구간부터 진행합니다.

## 활동 2: 얼마를 낼까요?

### 활동 방법

1. 오른쪽 위의 `얼마를 낼까요?` 버튼으로 활동을 전환합니다.
2. 과자 사진 오른쪽에 표시된 가격을 확인합니다.
3. 지갑의 돈을 같은 자리의 숫자 칸으로 옮깁니다. 각 자리에는 돈이 9개씩 준비되어 있습니다.
4. 목표 개수를 넘기거나 다른 자리에 놓으면 돈이 원래 위치로 돌아옵니다. 모든 숫자가 표시된 가격과 같아지면 완성입니다.
5. 화면 오른쪽 삼각형 버튼을 눌러 다음 문제로 넘어갑니다.

단계 구분 없이 지정된 과자 30종을 고정된 순서와 가격으로 진행합니다.
상단 다시 시작 버튼을 누르고 확인하면 현재 활동을 처음부터 시작합니다. 브라우저를 새로고침하면 두 활동 모두 초기화되고, 「얼마일까요?」 1단계가 표시됩니다.

드래그 대신 돈을 탭한 뒤 숫자 칸을 탭하거나, 키보드로 선택·이동할 수 있습니다.
두 활동은 오른쪽 위 버튼으로 전환하며, 전환해도 각 활동의 진행 상태가 유지됩니다.
