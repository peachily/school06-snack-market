## 상태와 불변 조건

`GameState`는 선택된 학생 ID와 세 `StudentSession`을 가집니다. 세션은 고유 ID, 독립 셔플한 30개 문제, 현재 인덱스와 전체 완료 여부를 보관합니다. 가격은 초기 세션에서 준비하며 렌더링 중 재생성하지 않습니다.

`QuestionState`는 과자 ID, 내부 정답·자릿값, 고정 현금 토큰 목록, 사용한 현금 ID 목록과 완료 여부를 가집니다. 표시 숫자와 사용 여부는 이 상태에서 계산합니다. 정답 가격 자체는 화면에 출력하지 않습니다.

현금 토큰은 고유 ID와 0~8 슬롯 인덱스를 가지며 사용해도 원본 배열에서 제거하지 않습니다. 지갑은 자리마다 9개 슬롯을 항상 렌더링하고 사용한 현금만 숨깁니다.

Reducer는 학생·세션·문제 ID를 확인해 오래된 이벤트를 거부합니다. 다른 자리, 중복 사용, 목표 초과는 같은 상태를 반환합니다. 모든 현금 사용과 네 자릿값 일치가 함께 충족되어야 완료됩니다. 완료된 문제만 다음으로 이동하며 30번째 이후에는 이동하지 않습니다.

## 상호작용과 완료

`GameActivity`가 `DragDropProvider`를 구성하고 `DraggableMoney`와 `DigitTarget`을 연결합니다. 정렬 API는 사용하지 않습니다. 포인터가 실제 확장 드롭 영역 안에 있어야 이동하며 가장 가까운 칸으로 자동 배치하지 않습니다. 키보드·탭은 동일한 상태 전이 함수를 호출합니다.

학생 전환·다시 시작·문제 이동 시 상호작용 영역을 새로 마운트해 이전 드래그와 선택을 정리합니다. 게임 상태는 별도로 유지됩니다. 완료 효과는 현재 화면에서 미완료→완료일 때만 실행되므로 완료 학생을 다시 선택해도 재생하지 않습니다. 숫자 결합은 완료 상태에서 유지되고, 다음 문제는 0과 기본 간격으로 시작합니다.

모든 세션은 React 메모리에만 있습니다. 브라우저 저장소·서버 저장은 없으며 새로고침 시 초기화됩니다.

## 자산과 접근성

과자와 현금은 `AssetImage`를 통해 원본 비율로 표시하고, 잘못된 경로나 로딩 실패는 플레이스홀더로 처리합니다. 화면에 필요한 이미지만 요청하며 비동기 디코딩을 사용합니다. 글꼴은 원본 Regular/Bold와 `font-display: swap`을 유지하고 제목·숫자에 쓰이는 Bold를 먼저 요청합니다.

아이콘에는 접근성 이름을 제공하고, 현금 선택 후 키보드 초점을 해당 숫자 칸으로 옮깁니다. Escape는 선택·드래그를 취소합니다. 완료 후 다음 버튼 또는 상단 다시 시작으로 초점이 이동합니다. `prefers-reduced-motion`에서는 숫자 이동과 폭죽을 생략합니다.
