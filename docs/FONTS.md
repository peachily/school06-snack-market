# 빙그레체 출처

- 배포자: 빙그레
- 공식 안내 및 사용 조건: https://www.bing.co.kr/news/media_font
- 공식 원본: https://www.bing.co.kr/font/Binggrae_TTF.zip
- 포함 파일: `Binggrae.ttf` (Regular 400), `Binggrae-Bold.ttf` (Bold 700)
- 저장 위치: `apps/web/public/fonts/`

공식 ZIP의 TTF 파일을 변환·수정 없이 그대로 사용한다. 빙그레 공식 안내는 개인·기업을 포함한 모든 사용자에게 무료 제공하며 글꼴의 판매를 금지한다. 웹에서는 두 굵기 모두 `font-display: swap`으로 로드한다.
