# 통합 검증 기록

2026-10-17, macOS에서 Node.js 24.22.0 / pnpm 10.34.7과 Chrome 155.0.8059.80으로 확인했습니다. 브라우저 검증은 로컬의 배포용 정적 빌드를 대상으로 했습니다.

## 실행 결과

| 명령 | 결과 |
| --- | --- |
| `pnpm lint` | 통과, 경고 없음 |
| `pnpm typecheck` | 통과 |
| `pnpm test` | 12개 파일, 81개 테스트 통과 |
| `pnpm build` | `apps/web/dist` 생성 |
| `pnpm check:assets` | 이미지 34개 존재, 누락 0, 잘못된 경로 0 |

Vitest에는 수준별 가격 경계·0 포함 사례, 수준 3의 모든 네 자리 수 9,000개 생성, 고유 과자 셔플, 고정 슬롯, 잘못된 이동·중복 이동·목표 초과 거부, 세 학생 상태 독립, 완료·다음·재시작을 포함합니다. 이번 통합 테스트는 세 학생을 번갈아 선택하며 90문제를 끝까지 진행하고, 현금을 역순으로 사용하며 수량과 완료 상태, 다른 학생 상태 불변을 검증합니다.

UI 테스트는 1020의 0인 자리, 탭·키보드, 학생 전환, 완료 재생 방지, 다음 연속 클릭, 30종 종료를 확인합니다. 아래 실제 브라우저 점검은 별도 임시 자동화로 수행했으며 `pnpm test`에 포함되지 않습니다.

## 정적 앱 브라우저 점검

- 최초 학생 1, 학생 1·2·3의 최대 현금 9·18·36개와 숫자 0000 확인.
- 학생 전환 후 부분 진행 복원, 현재 학생만 재시작, 확인 취소, 새로고침 후 세 학생 초기화 확인.
- 마우스 정답·오답·영역 밖 드롭, 확장 영역 가장자리 드롭, 슬롯 위치 유지 확인.
- 터치 에뮬레이션의 드래그와 탭 대체 입력, Enter 선택·이동, 드래그 중 학생 전환 확인.
- 잘못된 자리의 흔들림과 상태 불변, 사용한 현금 제거 확인.
- 완료 숫자 칸의 인접 경계와 내부 모서리, 폭죽 제거, 다음 버튼, 다음 연속 클릭과 초기화 확인.
- 동작 줄이기 설정에서 결합 전환 제거와 폭죽 숨김 확인.
- 전체 이미지 로딩, 두 굵기의 Binggrae 로드, 네 배경·테두리 색상의 계산값 일치 확인.
- 정상 로딩 시 브라우저 콘솔 오류·경고 및 페이지 예외 없음.
- 이미지 요청을 의도적으로 404로 응답시킨 별도 화면에서 플레이스홀더 확인. 이 경우 예상된 네트워크 404는 정상 로딩의 무오류 결과와 구분했습니다.

## 화면 크기

최대 36개 현금을 배치하고 이미지·숫자·지갑 비중첩, 이미지의 슬롯 내부 배치, 드롭 영역 비중첩, 가로 넘침 없음을 확인했습니다.

| 화면 | 결과 | 현금 버튼 최소 크기(약 px) |
| --- | --- | --- |
| 1920×1080 | 한 화면에 표시 | 129×68 |
| 1280×720 | 한 화면에 표시 | 79×46 |
| 1366×768 | 한 화면에 표시 | 86×45 |
| 1024×768 | 태블릿 가로, 한 화면에 표시 | 59×48 |
| 390×844 | 모바일 세로, 좁은 화면 드래그 확인 | 27×53 |
| 360×640 | 세로 스크롤 허용, 좁은 화면 드래그 확인 | 24×54 |

모바일은 4개 자리와 3×3 슬롯의 대응을 유지하므로 현금 터치 영역의 가로 폭이 전자칠판보다 작습니다. 화면 밖의 아래 슬롯은 스크롤로 접근합니다. 실제 수업은 가로 전자칠판을 우선합니다.

## 성능·구조 점검

프로덕션 JS는 약 336KB, gzip 약 107KB이고 CSS는 약 18KB, gzip 약 5KB입니다. 새 런타임 의존성은 추가하지 않았습니다. 정답은 내부 세션에만 있으며 DOM에는 현재 표시 숫자만 전달합니다. 코드의 `any`, 브라우저 영구 저장소, 외부 이미지·폰트 요청, 사용하지 않는 데모 코드는 없습니다.

원본 TTF 두 파일은 합계 약 13MB입니다. 원본 유지 조건에 따라 서브셋·변환하지 않았으며, Bold preload와 swap을 적용했습니다. 느린 네트워크의 최초 방문에서는 대체 글꼴이 잠시 표시될 수 있습니다. 해시 JS/CSS는 장기 캐시하고 원본 이미지·폰트는 교체를 반영하도록 재검증합니다.

## 아직 확인하지 않은 환경

- 실제 전자칠판·태블릿·휴대전화 하드웨어에서의 터치와 멀티터치
- Safari·Firefox와 기기별 화면 읽기 도구
- 느린 실제 교실 네트워크의 초기 글꼴 로딩 시간
- Cloudflare 계정 연결, 원격 빌드, CDN 응답 헤더, main 자동 배포와 pages.dev 접속

배포와 실기기 확인은 [배포 안내](DEPLOYMENT.md)의 마지막 점검 항목에 따라 진행합니다. 로컬 빌드 성공을 실제 배포 성공으로 간주하지 않습니다.
